# Классификация Anthropic

Включение: `AI_PROVIDER=anthropic`, `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL`.

Классификация берёт тот же `ANTHROPIC_MODEL`, что маркетинг, сигналы и разбор About. Это Sonnet. Текущий идентификатор на 12 октября 2026 — `claude-sonnet-5-5`. Также известны цены `claude-sonnet-5` и `claude-sonnet-4-6`. Снятый или неизвестный идентификатор не вызывается: неизвестная цена блокирует запрос и не считается нулём.

Тарифы с публичной страницы цен Anthropic, для обычного запроса без кэша и batch:

| Модель | Вход / 1M | Выход / 1M |
| --- | --- | --- |
| claude-sonnet-5-5 | $2 | $10 |
| claude-sonnet-5 | $2 | $10 |
| claude-sonnet-4-6 | $3 | $15 |
| claude-haiku-5-5 | $0.10 | $0.50 |
| claude-haiku-4-5 | $1 | $5 |

Промпт длиннее 100 000 токенов этот путь не отправляет. У Haiku 5.5 выше этого порога другой тариф, и этот путь его не угадывает. Фрагмент классификации короче.

В модель уходят короткий бриф, фрагмент до 1500 символов и URL. Не уходит полный HTML. Системная инструкция говорит, что фрагмент — недоверенные данные. Ответ — JSON заданной схемы; лишние поля игнорируются. Невалидный JSON становится `INSUFFICIENT_EVIDENCE` без цитаты.

`confidence` сохраняется как некалиброванная оценка модели, не как вероятность.

Второй вызов (поле `reasoning` у `LeadPipeline`) делается только если он передан и случай неоднозначный. `pipeline_from_env` его не включает.

Пока ключ не задан владельцем, платных вызовов нет.
