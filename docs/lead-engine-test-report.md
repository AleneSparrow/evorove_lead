# Отчёт о прогонах

Среда: Python 3.12, пакет установлен в editable-режиме. Платных API не было.

## Набор pytest

До правок: 260 прошли, 1 упал. Падение — `tests/test_rendering.py::test_renders_real_javascript_generated_content`: пакет Playwright есть, бинарника Chromium нет. Комментарий теста обещал пропуск. Теперь при отсутствии бинарника тест пропускается, а не падает.

Полный прогон после правок:

```text
python3 -m pytest -q
```

**272 passed, 1 skipped**. Пропуск — рендер SPA без установленного Chromium. Второй тест рендера (обрыв навигации) прошёл: ошибка запуска оборачивается в `RenderRejected`.

Новые проверки — `tests/test_lead_engine_controls.py`: класс доказательства, экран следа, кэш и повтор поиска, бюджет прогона, пропуск paused-шаблона, отказ от непознанной цены, списокная цена Haiku `0.00012` USD, одноразовая заявка Cold в SQLite, потолок outbox, синтетическая оценка с `real_world_accuracy=false`.

## PostgreSQL 16

Поднят локальный сервер только для проверки. Боевая база не трогалась.

`alembic upgrade head` на пустой базе прошёл с `0001` по `0009`.

Восемь потоков одновременно заявили один и тот же контакт. Успешная заявка ровно одна.

Накопление `pipeline_spend`: 2 вызова модели, 3 поисковых запроса, 100 входных токенов.

Колонка `candidates.evidence_class` есть. Таблицы `cold_identity_claims` и `pipeline_spend` есть.

SQLite не проходит старые миграции с `CHECK` вне batch-режима. Это прежнее ограничение `0002`, не регрессия `0009`. Тесты склада по-прежнему создают схему через `create_all` на SQLite.
