# Наблюдения владельца

Не веб-справочник и не купленная база. Сюда владелец сама кладёт людей, за которых может ответить: скопированный публичный пост, знакомый человек, факт, который она видела.

Формат: файлы `.jsonl`, одна запись на строку. README и `.env` сюда не входят.

Поля:

| Поле | Обязательно | Смысл |
| --- | --- | --- |
| `name` | нет | Имя, если известно |
| `email` | для канала `email` | Адрес, которым цикл 2 потом сможет писать |
| `phone` | для канала `sms` | Телефон, которым цикл 2 потом сможет писать |
| `observed_fact` | да | Почему этот человек здесь. Не дописывать оффер к номеру |
| `observed_source` | да | Откуда факт: «скопировала публичный пост», «знакома лично» |
| `channel` | да | Только `email` или `sms` |

Пример строки:

```json
{"name":"Jordan Lee","email":"jordan@example.com","observed_fact":"Public post asking about weekend catering for busy parents.","observed_source":"owner-copied public post, 2026-09-01","channel":"email"}
```

Строка без факта — свалка контактов, её отбрасываем. Движок ещё раз проверит, что факт связан с понятым оффером.

Не класть ключи и `.env`. Не скрейпить LinkedIn и чужие каталоги. Этот репозиторий не отправляет письмо и SMS.
