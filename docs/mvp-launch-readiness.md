# Готовность к контролируемому пилоту

Это не разрешение включать прод. Живое качество лидов ещё не мерялось на реальной выдаче.

## Что пилот может сделать

1. Владелец указывает публичный сайт (`POST /api/v1/internal/searches`, тело `{business_id, site_url, business_archetype}`).
2. Движок читает бриф. Сайт — не список лидов.
3. Если задан `WEB_SEARCH_BASE_URL`, строятся гипотезы и идётся свой SearxNG.
4. След проходит язык, гео, свежесть, дедуп и отбор.
5. Человек с просьбой и контактом, или компания из аудитории брифа, может уйти в Cold через существующий `crm_touch`. Сообщение человеку не отправляется.
6. `GET /api/v1/internal/searches/{business_id}` отдаёт статус, число Cold и отчёт `cost`.
7. Исход сделки возвращается отдельно, без PII: `POST /api/v1/internal/hypothesis-outcomes`.

## Что должно быть у владельца

| Имя | Зачем | Кто вписывает |
| --- | --- | --- |
| `DATABASE_URL` | Склад цикла 1, Postgres | Владелец, не агент |
| `WEB_SEARCH_BASE_URL` | Свой SearxNG с JSON | Владелец |
| `CRM_BASE_URL`, `INTERNAL_TASK_SECRET` | Кладка в Cold и приём исходов | Владелец |
| `AI_PROVIDER=anthropic`, `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | Необязательный разбор брифа и запасное чтение страницы | Владелец |
| `LEAD_PRICED_MODEL` и две цены за миллион токенов | Если модель не из таблицы в `docs/llm-cost-optimization.md` | Владелец |
| Потолки `LEAD_MAX_*`, `LEAD_CLIENT_MAX_*` | Если дефолтов 24 вызова и 40 запросов мало или много | Владелец |

Ключи в репозиторий не класть. Агент их не читает.

Сервисы: Postgres цикла 1 (не база CRM), приватный SearxNG, уже существующий CRM для Cold. Отдельный фронт не нужен.

## Порядок пилота

1. Поднять Postgres и прогнать `alembic upgrade head`.
2. Поднять SearxNG. В `.env` у владельца — только её URL, без ключа поисковика.
3. Не ставить `AI_PROVIDER`, пока не названа цена модели. Движок тогда работает на буквальном брифе, без модели.
4. Прогнать клиента 0: `python -m evorove_lead.client_zero`. Ожидание без URL поиска — выход 2, `messages_sent=0`. С URL — счётчики, без печати почты и телефона.
5. Один `business_id` тестового тенанта, один публичный сайт. Смотреть Cold и `cost`.
6. Сверить руками 20–30 следов: класс, цитата, URL. Это и есть первая живая оценка. Синтетический отчёт её не заменяет.
7. Рассылку не включать. Цикл 2 живёт в другом репозитории.

## Блокеры пилота

- Нет своего SearxNG — живого поиска нет. Это не баг отбора.
- Нет Postgres — склад и заявка Cold не сохраняются между процессами.
- Модель с неизвестной ценой — вызов блокируется намеренно.
- Качество на реальной выдаче не посчитано.

Движок цикла 1 по-прежнему запускается сам, без стратегии роста. Стратегию этот репозиторий не выбирает и не исполняет продажи.
