# Стоимость цикла 1

Учёт — `cost_ledger.CostLedger`, таблица `llm_usage`, поля `input_tokens`, `output_tokens`, `cost_usd_micros` на квалификации.

Потолки по умолчанию, переопределяются переменными окружения:

| Переменная | По умолчанию |
| --- | --- |
| LEAD_MAX_CLASSIFICATIONS_PER_RUN | 40 вызовов |
| LEAD_MAX_USD_PER_RUN | $2 |
| LEAD_MAX_USD_PER_BUSINESS | $25 |
| LEAD_MAX_USD_GLOBAL | $100 |
| LEAD_MAX_SEARCH_REQUESTS | 30 HTTP к SearxNG |

Исчерпание — жёсткий стоп, без запроса в Anthropic. Кэш по хешу фрагмента и модели не тарифицируется повторно. Одинаковый URL и хеш в складе не перезаписывает старую квалификацию.

Пример цены Haiku 5.5: 1000 входных и 100 выходных токенов = 150 микродолларов ($0.00015).

Фактический расход этого изменения: 0 токенов и $0. Платный API не вызывался.

Бюджет гипотез `query_budget` по-прежнему ведёт `reweight_hypotheses.py`. Отзыв `irrelevant`, `incorrect_icp` или `outdated` уменьшает бюджет только связанной гипотезы на 1, не ниже 0 и не выше `MAX_QUERY_BUDGET`. `relevant` увеличивает на 1. Остальные виды отзыва пишутся, бюджет не двигают.
