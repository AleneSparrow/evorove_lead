## Вход: материалы, которые положил владелец

Агент **не ищет** объявления в чужих кабинетах и **не скрейпит** чужие или платные рекламные поверхности.

Владелец сама кладёт файлы в [`owner-materials/`](../owner-materials/). Допустимый вход:

- её текст объявления (копия, которую она имеет право отдать);
- URL **её** сайта или лендинга;
- её описание услуг своими словами.

Не вход этого среза:

- чужие объявления, снятые скрейпом;
- платный/закрытый контент;
- секреты, ключи, `.env`;
- подключение Bing / Google / Meta Ads по OAuth (владелец введёт секреты сама, отдельным шагом, не сейчас).

---

## Понимание оффера и аудитории

Из положенных материалов позже получается структурированное понимание:

- что продаём (как сказано в материалах, без домысла);
- кому это **может** подойти;
- чего агент **не имеет права** обещать.

Запрещено выдумывать цену, скидку, гарантию и юридическое утверждение, которых нет в материалах владельца. Отраслевых вилок в коде нет: юриспруденция — не продукт, а возможный вход на рынок.

Business DNA из репозитория продажи не копировать целиком — только факты, нужные поиску, когда поиск появится.

## Выход: кандидат

Результат цикла — не «база контактов». Запись допустима только если есть все три поля:

| Поле | Смысл |
| --- | --- |
| **identity** | Личность, которую цикл 2 **потом** сможет адресовать (не отправка сейчас) |
| **reason** | Почему этот человек здесь, привязка к офферу/аудитории |
| **reason_source** | Откуда взялась причина (какой материал, какой наблюдаемый факт) |

Запись **без причины отклоняется**. Контакта мало. Пустая или пробельная причина — не кандидат.

Это ещё не продажа, не заполненная CRM-карточка и не слот в календаре.

Инвариант в коде (без поиска людей): `src/evorove_lead/candidate.py`.

### Handoff 1→2 (когда появится)

Найденный человек + причина + источник + канал, которым цикл 2 потом можно писать. Письмо и GREET — не здесь. Пока между репозиториями нет очереди/API — не делать вид, что контуры уже склеены.

Горячий лид (согласен на услугу, готов записаться, ещё не стоит в календаре) — **не** этот контракт.

## Явные не-цели

Цикл 1 **не** делает:

- исходящее письмо, SMS, звонок, очередь «написать на этот телефон»;
- разговор продажи, возражения, GREET, цитаты цены;
- календарь, бронь, смету, `ProcessEngine`;
- виджет или intake «нам уже написали» как генерацию;
- поиск людей, обогащение, скрейп LinkedIn — не на этом срезе;
- `SalesStage` / `ProcessState` (это продажа и обязательства кейса);
- Lemon Squeezy, Twilio, встраиваемый чат.

## Рекламные библиотеки и кабинеты (не этот срез)

| Источник | Статус |
| --- | --- |
| Материалы, которые владелец положила сама | Вход цикла 1 |
| Microsoft Ad Library API | Публичный, но **только показы в EEA** (DSA). Не источник истины для рынка США / SMB. Позже — **опциональный** исследовательский вход, не ядро и не этот срез |
| Google Ads Transparency Center | Не скрейпить внутренности |
| Bing / Google / Meta Ads (свой кабинет) | Отдельный шаг с OAuth; секреты вводит владелец, агент их не просит и не вставляет |
