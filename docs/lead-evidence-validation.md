# Проверка доказательств

Цитата принимается, только если её нормализованный текст есть в извлечённом фрагменте. URL в ответе модели должен совпасть с URL документа после нормализации.

Дата публикации берётся из разметки (`time datetime`, `article:published_time` и соседние meta). Дата, которой нет в разметке, в запись не попадает, даже если её придумала модель. Автор — только из meta `author` / `article:author`.

Если цитата не подтверждена, `EXPLICIT_INTENT` и `INFERRED_OPPORTUNITY` понижаются до `INSUFFICIENT_EVIDENCE` (сегмент `review`). Страница, которая продаёт ту же услугу и не содержит просьбы покупателя, помечается `IRRELEVANT`.

`ICP_MATCH` остаётся prospect: совпадение с портретом не считается намерением купить.

Пустая страница, спам, непубличный URL, страна не US в двухбуквенном `geo_hint` и дата старше пяти лет отсекаются до модели. Отсутствие ключевых слов услуги и письменность текста сами по себе не отсекаются.
