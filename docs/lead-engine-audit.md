# Аудит LeadGenerationEngine

Дата проверки: 12 октября 2026. Репозиторий — только цикл 1. Якорь продукта не менялся: бриф → открытый веб → повторный отбор → CRM Cold. Письмо, бронь и виджет сюда не входят.

Контракт цикла остаётся в [`cycle-1-contract.md`](cycle-1-contract.md). Этот файл — что реально делает код и что в нём было сломано.

## Пайплайн, как он есть

| Имя из задачи | Где в коде |
| --- | --- |
| Business DNA | Бриф: `offer_reader.py`, снимок `briefs`, архетип задаёт владелец |
| Разбор аудитории | `marketing_analysis.py`, только если `AI_PROVIDER=anthropic` |
| Гипотезы / ICP | `hypothesis.py`, `pattern_library.py` |
| Поиск | `web_search.py` (свой SearxNG) + `web_people_search.py` |
| След и доказательство | `traces`, `TraceFinding` |
| Отбор | `selection.py`, `candidate.py` |
| Состязательная проверка | Регекс конкурента в `selection.py`. Отдельной LLM-проверки нет |
| Память гипотез | `reweight_hypotheses.py`, бюджет `query_budget` |
| Ранжирование | `ranking.py` поверх fit / evidence / класса доказательства |
| Движок | `engine.py`, `LeadGenerationEngine` |
| CRM Cold | `crm_touch.py`, не сообщение человеку |
| Outbox | `crm_deliveries` |
| Обратная связь | `POST /api/v1/internal/hypothesis-outcomes` |

Поиск людей по умолчанию выключен (`UnconnectedPeopleSearch`). Живой коннектор включается только переменной `WEB_SEARCH_BASE_URL`.

## Что было сломано или не доведено

1. Бюджет гипотезы писался в склад, но следующий прогон строил новые строки и искал все шаблоны заново. `paused` и `query_budget = 0` на поиск не влияли.
2. Ошибка SearxNG глоталась с первой попытки. Повтора не было. Успешный ответ не кэшировался.
3. У следа были поля языка и гео, коннектор их не заполнял. Чужая страна и нелатинский текст не отсекались до скачивания страницы.
4. Дата публикации из JSON SearxNG не читалась, старый след не отбрасывался.
5. Три клиента Anthropic не читали `usage` и не имели потолка вызовов. Неизвестная цена модели нигде не отличалась от нуля, потому что денег код вообще не считал.
6. Один и тот же промпт мог уйти в модель повторно.
7. Совпадение служебного слова без просьбы получало `evidence = 0.5` и всё равно попадало в Cold без класса. Теперь у такого следа класс `INSUFFICIENT_EVIDENCE`. На живом гипотезном пути человек с этим классом или с голым `ICP_MATCH` в Cold не кладётся. Мост со старыми тестами (JSONL владельца) этот класс по-прежнему может положить в Cold: тесты это фиксируют. Класс при этом не называется покупкой.
8. Повторный Cold держался на чтении уже принятых контактов. Два параллельных прогона могли оба пройти проверку. Появилась таблица `cold_identity_claims`.
9. Зависший статус `running` после падения процесса больше не блокирует цель навсегда: через 2 часа прогон считается брошенным и может начаться снова.
10. Outbox CRM повторял доставку без потолка попыток. Теперь не больше 8.
11. Тест рендера SPA падал, если пакет Playwright стоял, а бинарник Chromium нет. Модульный комментарий обещал пропуск. Так и сделано.

## Чего в репозитории нет и не добавлялось

Growth Strategy Engine, Content Factory, рассылка, GREET, слот, отраслевые форки, скрейп LinkedIn и внутренностей Google Ads. Microsoft Ad Library по-прежнему не справочник людей США.

Живой платный поиск не подключался. Источник URL — свой SearxNG.
