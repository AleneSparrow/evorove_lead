# Материалы бизнеса

Необязательная папка. Основной вход цикла 1 — URL публичного сайта бизнеса. Движок читает страницу сам. Владелец не обязан сюда ничего печатать.

Сюда можно положить дополнительную копию, если она сама так хочет. Не класть ключи, пароли и `.env`.

## Клиент 0

Для клиента 0 (`python -m evorove_lead.client_zero`) эта папка теперь реально читается — до живой страницы `evorove.com`, не вместо неё. Причина: живая страница написана лозунгами и FAQ-вопросами, которые эвристика `offer_reader.py` разбирает плохо (см. `docs/client-zero-pilot-checklist-ru.md`). [`service.txt`](service.txt) — черновик короткого честного описания обычными предложениями, составленный агентом 17 сентября 2026 **только** из уже опубликованных слов `evorove.com` и `FOUNDATION.md`, ничего не выдумано. Владельцу стоит прочитать и поправить своими словами перед тем, как считать его окончательным — файл напрямую становится текстом брифа и поисковых запросов.
