# Материалы бизнеса

Сюда владелец **сама** кладёт то, из чего цикл 1 может понять предложение:

- текст её объявления;
- URL её сайта;
- описание услуг своими словами.

Агент не скрейпит чужие объявления, не заходит в рекламные кабинеты, не открывает URL из файла и не просит секреты. URL — указатель на потом; текст объявления и описание услуг нужно положить сюда файлом.

Пока здесь только этот README, оффера нет: инструкции — не материал бизнеса.

Не класть сюда ключи, пароли и `.env`.
