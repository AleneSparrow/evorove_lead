# Стоимость LLM

Сеть модели по-прежнему выключена, пока владелец не поставит `AI_PROVIDER=anthropic` и сама не впишет ключ. Этот прогон ключ не читал и платных вызовов не делал.

## Зачем вообще вызывается модель

| Вызов | Стадия | Когда |
| --- | --- | --- |
| Разбор брифа, 2–3 аудитории | `deep_reasoning` | Один раз на прогон, только если анализатор включён |
| Имя владельца на сайте компании | `deep_reasoning` | Только если регекс на уже скачанной странице никого не нашёл |
| Новость рынка | `low_cost_classification` | Один раз на новый URL новости |
| Дешёвое подтверждение `INFERRED_OPPORTUNITY` | `low_cost_classification` | Только если в движок передан confirmer. По умолчанию его нет |

Явная просьба (`EXPLICIT_INTENT`) в модель повторно не отправляется. Отбор, гео, язык, свежесть, дедуп и ранг считаются без модели.

Пакетный вызов есть в `qualification.confirm_batch` для прогона оценки. Живой движок им не пользуется: один битый элемент не должен обнулять весь заход.

## Цена

Известные списокные цены USD за миллион токенов, не счёт провайдера:

| Модель | Вход | Выход |
| --- | --- | --- |
| `claude-3-5-haiku-20241022` | 0.80 | 4.00 |
| `claude-3-haiku-20240307` | 0.25 | 1.25 |
| `claude-3-5-sonnet-20241022` | 3.00 | 15.00 |

Другая модель без `LEAD_PRICED_MODEL` и пары `LEAD_MODEL_INPUT_USD_PER_MILLION` / `LEAD_MODEL_OUTPUT_USD_PER_MILLION` считается непознанной. Вызов не уходит. `cost_usd` становится `null`, не `0`.

SearxNG свой. Поле `search_vendor_usd` всегда `null`: это не ноль долларов вендору.

Если провайдер вернул `usage`, токены измеренные. Если нет — оценка `длина / 4` и флаг `tokens_estimated`.

Локальный замер без сети, модель Haiku, usage 100 входных и 10 выходных токенов:

`100 * 0.80 / 1_000_000 + 10 * 4.00 / 1_000_000 = 0.00012` USD.

Повтор того же промпта — попадание в кэш прогона, второй сетевой вызов не делается (`llm_calls` остаётся 1).

## Потолки

| Переменная | Смысл | Если не задана |
| --- | --- | --- |
| `LEAD_MAX_LLM_CALLS` | Вызовы модели за прогон | 24 |
| `LEAD_MAX_SEARCH_REQUESTS` | Запросы поиска за прогон | 40 |
| `LEAD_MAX_USD` | Доллары за прогон | Нет долларового потолка, есть потолок вызовов |
| `LEAD_CLIENT_MAX_LLM_CALLS` | Накопленные вызовы тенанта | Не проверяется |
| `LEAD_CLIENT_MAX_SEARCH_REQUESTS` | Накопленные запросы тенанта | Не проверяется |
| `LEAD_GLOBAL_MAX_LLM_CALLS` | На процесс | Выключено |
| `LEAD_GLOBAL_MAX_SEARCH_REQUESTS` | На процесс | Выключено |

При упоре прогон заканчивается со статусом `no_fit` или с уже найденными людьми и `stopped_reason=budget_exhausted`. Исключение наружу из поиска не летит.

Отчёт лежит в `GenerationResult.cost` и, после фонового прогона, в `GET /api/v1/internal/searches/{business_id}` в поле `cost`.
