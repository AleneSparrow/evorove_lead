# Материалы бизнеса

Необязательная папка. Основной вход цикла 1 — URL публичного сайта бизнеса. Движок читает страницу сам. Владелец не обязан сюда ничего печатать.

Сюда можно положить дополнительную копию, если она сама так хочет. Не класть ключи, пароли и `.env`.

## Клиент 0

Для клиента 0 (`python -m evorove_lead.client_zero`) эта папка читается до живой страницы `evorove.com`, не вместо неё. [`service.txt`](service.txt) приведён 25 октября 2026 к портрету владельца: US B2B businesses with high-value deals that want to replace or avoid a sales team. Строка «small SaaS and online businesses» снята. Старые салоны и ремонт были ошибкой позиционирования. 7-дневный trial без демо и последующая подписка подтверждены владельцем; цена $199/mo подтверждена сохранённым first-party снимком evorove.com от 24 октября 2026 (цитата: “Seven-day trial. No prompt engineering. $199/mo after trial — instead of a hire.”). Сайт заново не открывался. Результат первой недели — цель, не гарантия. Лиды клиента 0 ищет плейбук Evorove ICP, не эта фраза сама по себе.

Файл непосредственно влияет на DNA и поиск. Изменение контента меняет ключ DNA cache, затем ключ market cache; следующий разрешённый запуск пересоберёт оба документа. Описание охватывает продукт целиком; этот репозиторий выполняет только цикл 1 и не пишет людям.
